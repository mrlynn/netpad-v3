# AI GitHub Repository Auditor - Built on NetPad Platform

You are an expert developer specializing in NetPad.io platform development, GitHub integrations, and AI pattern detection. Your task is to help design and build an AI GitHub Repository Auditor application using NetPad as the foundation.

## Project Overview

Build a NetPad application that allows developers to input a GitHub repository URL and receive a comprehensive audit report analyzing the likelihood that code contributions and pull requests were generated by AI rather than written by humans.

## Why NetPad as the Foundation

NetPad provides the complete infrastructure needed for this application:
- **Forms**: Repository input form, audit configuration, filtering options
- **Workflows**: Automated analysis pipelines with AI classification nodes
- **Search Forms**: Query and filter audit results from MongoDB
- **MongoDB Integration**: Native storage for audit data, contributor profiles, detection patterns
- **AI Nodes**: Built-in AI classify and AI generate capabilities for pattern detection
- **Webhook Triggers**: GitHub webhook integration for real-time monitoring

## Phase 2: Workflow Design

### 2.1 Main Audit Workflow

**Trigger**: Form Submission (Repository Submission Form)

**Node Flow**:
```
[Form Trigger] 
    → [Set Variable: auditId] 
    → [MongoDB Write: Create audit record with status "pending"]
    → [HTTP Request: GitHub API - Fetch repo metadata]
    → [Conditional: Is repo accessible?]
        → YES: [HTTP Request: Fetch commits]
        → NO: [MongoDB Write: Update status "failed"] → [Email: Notify failure]
    → [Loop: For each commit batch]
        → [AI Classify: Analyze commit messages for AI patterns]
        → [Transform: Extract code diff patterns]
        → [AI Classify: Analyze code structure]
        → [MongoDB Write: Store commit analysis]
    → [HTTP Request: Fetch PRs]
    → [Loop: For each PR]
        → [AI Classify: Analyze PR description]
        → [AI Classify: Analyze review interactions]
        → [MongoDB Write: Store PR analysis]
    → [Custom Code: Calculate aggregate scores]
    → [MongoDB Write: Update audit with final results]
    → [Email: Send completion notification with summary]
```

### 2.2 Contributor Analysis Workflow

**Trigger**: Conditional from main workflow (if includeContributorAnalysis = true)

**Node Flow**:
```
[Manual Trigger: auditId input]
    → [MongoDB Query: Get unique contributors from audit]
    → [Loop: For each contributor]
        → [HTTP Request: GitHub API - Fetch contributor profile]
        → [HTTP Request: Fetch contributor's commit history]
        → [AI Classify: Analyze contribution patterns]
        → [Transform: Calculate consistency metrics]
        → [MongoDB Write: Store contributor profile]
    → [Custom Code: Cross-reference patterns across contributors]
    → [MongoDB Write: Update audit with contributor insights]
```

### 2.3 Scheduled Re-scan Workflow

**Trigger**: Schedule (cron: daily at 2am)

**Node Flow**:
```
[Schedule Trigger]
    → [MongoDB Query: Find repos with monitoring enabled]
    → [Loop: For each monitored repo]
        → [HTTP Request: Check for new commits since last scan]
        → [Conditional: New commits found?]
            → YES: [Trigger main audit workflow with incremental scope]
            → NO: [Continue to next]
    → [MongoDB Write: Log scan completion]
```

## Phase 4: AI Detection Patterns

### 4.1 Configure AI Classify Nodes

**Commit Message Classifier**
```javascript
// AI Classify node configuration
{
  categories: [
    { id: "likely_ai", name: "Likely AI Generated", description: "Shows strong AI writing patterns" },
    { id: "possibly_ai", name: "Possibly AI Generated", description: "Some AI indicators present" },
    { id: "likely_human", name: "Likely Human Written", description: "Natural human writing patterns" }
  ],
  prompt: `Analyze this commit message for AI generation patterns:
    - Formulaic structure (type: description format without variation)
    - Overly comprehensive explanations for simple changes
    - Generic phrases like "refactor for better maintainability"
    - Perfect grammar with no personality or shortcuts
    - Lack of contextual references human devs would make
    
    Commit message: {{input.message}}
    Files changed: {{input.filesChanged}}
    
    Classify and explain your reasoning.`
}
```

**Code Pattern Classifier**
```javascript
{
  categories: [
    { id: "ai_signatures", name: "AI Signatures Detected" },
    { id: "mixed_signals", name: "Mixed Signals" },
    { id: "human_patterns", name: "Human Patterns" }
  ],
  prompt: `Analyze this code diff for AI generation signatures:
    - Suspiciously comprehensive inline comments
    - Formulaic error handling (generic try-catch patterns)
    - Overly descriptive variable names that read like documentation
    - Boilerplate-heavy implementations
    - Orphaned explanatory comments disconnected from code
    - Consistent formatting that never varies
    
    Code diff: {{input.diff}}
    Language: {{input.language}}
    
    Identify specific patterns and score confidence.`
}
```
